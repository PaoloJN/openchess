# Design Decisions

Why the OpenChess hardware is shaped this way.

## Two PCBs Plus A Panel Harness

The matrix board carries the repeated sensor and LED hardware. The controller
carries the ESP32, power, row pullups, column driver, LED level shifter,
battery monitor, and connectors. The OLED and buttons live on flying leads so
they can sit wherever the case wants them without a panel PCB.

Splitting the boards keeps the big repetitive board simple and lets the
controller be respun (v2) without touching the matrix.

## DRV5032FC SOT-23 Hall Sensors

Compact, JLC-assemblable, and good enough to sense a small magnet through
the top plate. The alternative was 64 hand-soldered through-hole sensors.

## WS2812B Corner LEDs

One data line instead of 81 driven outputs. A 9x9 corner grid means a square
lights up as its four corners and an LED is shared by up to four squares,
which gives the "glow around the square" look.

## Scan Support On The Controller

Column power is switched one column at a time through a TBD62783A high-side
driver, rows are read through pullups on the controller. The matrix only
carries the parts that repeat 64 or 81 times.

## Scripted Matrix Generation

The matrix has a few hundred repeated parts. Placement and routing were
generated by scripts under `hardware/hardware-board/scripts/` to avoid
copy-paste errors.

## Skipped The 3x3 Validation Board

An early plan was a small 3x3 validation board before ordering the full
matrix. The full 8x8 was ordered directly and worked. The 3x3 project was
deleted.

## Controller v2 Integrates The Modules

v0.1 used a DevKitC and a Lipo Rider Plus on headers. The Lipo Rider's IP5306
would not run the board on battery, and the DevKitC's UART pins were spent on
I2C. v2 puts an ESP32-WROOM-32E, CH340C USB-C, BQ24074 charger, and TPS61022
boost directly on the PCB, moves I2C to GPIO21/22, and keeps the matrix
connector contract identical so the same matrix board plugs in.

## Fusion 360 Case With A Swappable Top

Case walls and front panel print as one part, the back cover clamps the PCB
stack, and the top plate is a separate screw-on piece so a two-color printed
board and a laser-cut plexi board share one mounting interface. Heat-set
inserts replaced hex-nut corners after the corner test prints.
