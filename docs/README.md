# OpenChess Docs

Active docs are for the current split-board hardware under `hardware/`.
Historical rev0.1 integrated-board notes live under `docs/archive/`.

## Active Docs

| File | Purpose |
|---|---|
| `../STATUS.md` | Current project state and next steps |
| `../hardware/DESIGN_NOTES.md` | Hardware decisions and board contracts |
| `inter-board-connector.md` | Matrix and control-panel connector pinouts |
| `gpio-map.md` | Provisional ESP32 GPIO plan |
| `bom.md` | Prototype BOM by board |
| `assembly.md` | Current expected build order |
| `design-decisions.md` | Why the design uses this architecture |
| `kicad-routing-playbook.md` | PCB layout/routing notes for the split boards |

## Archived Docs

`archive/rev0.1/` contains old single/integrated-board reviews and walkthroughs.
`archive/superpowers/` contains old generated plans and specs from prior directions.
Keep archived docs for history, but do not treat them as active implementation guidance.
