# OpenChess Hardware

Clean split-board hardware workspace.

```text
hardware-board/      matrix board: Hall sensors, WS2812 LEDs, connector
hardware-controller/ controller board: ESP32, power, drivers, panel connector
hardware-control-panel/ physical side panel: buttons + status LEDs
```

The old top-level hardware projects were archived to
`../delete/old-hardware-2026-06-04/`.

Start with [DESIGN_NOTES.md](DESIGN_NOTES.md), then use each board's
`scripts/README.md` for generation steps.
