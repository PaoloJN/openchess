# Errata

One file per fabricated board revision documenting bugs found after fab.

Format: `rev<N>.md` (e.g. `rev2.md` for the 2.0 board).

Each file should list:
- Issue (what's wrong)
- Severity (cosmetic / functional / blocking)
- Workaround for existing boards (rework note, firmware patch, etc.)
- Fix planned for next rev

Currently empty — no boards have been fabricated yet.
